# US-012 - Phase de jeu : chrono, soumission et suivi

**En tant que** joueur

**Je veux** disposer d'un compte à rebours fiable, soumettre une seule fois et voir qui a soumis

**Afin de** jouer équitablement sans dévoiler les réponses des autres.

## Critères d'acceptation

- Le compte à rebours est piloté par le serveur (source de vérité), affiché en `MM:SS` avec un code couleur (vert / orange / rouge).
- Un joueur ne peut soumettre qu'une seule fois ; une seconde soumission est refusée.
- Un non-participant ne peut pas soumettre ; un code de plus de 10 000 caractères ou un langage hors liste est refusé.
- Le statut des autres joueurs (a soumis / en attente) est visible sans révéler leur code.
- Pendant la partie, un joueur ne voit que sa propre soumission.

**Dépendances :** US-011

# US-007 - Rejoindre une salle (code ou aléatoire)

**En tant que** joueur

**Je veux** rejoindre une salle via son code ou en matchmaking

**Afin de** jouer rapidement, même sans partenaire prévu.

## Critères d'acceptation

- Un code à 8 caractères alphanumériques (insensible à la casse) permet de rejoindre la salle.
- Un code inexistant est refusé ; une salle déjà lancée ou complète est refusée ; un joueur déjà présent est refusé.
- Le matchmaking propose une salle disponible ; s'il n'y en a aucune, un message invite à en créer une.
- Une fois la salle rejointe, le joueur est redirigé vers la salle d'attente.

**Dépendances :** US-006

# US-004 - Changement de mot de passe

**En tant que** joueur

**Je veux** modifier mon mot de passe depuis mon profil

**Afin de** sécuriser mon compte.

## Critères d'acceptation

- Le profil propose un formulaire « mot de passe actuel + nouveau + confirmation ».
- Un mot de passe actuel incorrect est refusé avec un message clair.
- Un nouveau mot de passe non conforme aux règles de sécurité est refusé.
- Une modification réussie affiche une confirmation.

**Dépendances :** US-002

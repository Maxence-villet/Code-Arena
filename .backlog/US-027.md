# US-027 - Sécurité des soumissions de code

**En tant que** joueur

**Je veux** que mon code ne soit jamais exécuté sur le serveur et que les entrées soient validées

**Afin de** soumettre sereinement et en toute confiance.

## Critères d'acceptation

- Le code soumis n'est jamais exécuté ; il est uniquement analysé statiquement.
- La taille est limitée à 10 000 caractères et le langage doit appartenir à une liste blanche.
- Les motifs d'injection de commandes sont rejetés avec un message clair.
- Le code est toujours affiché en lecture seule, sans risque XSS.
- Un joueur ne peut pas accéder aux soumissions des autres pendant la phase de jeu.

**Dépendances :** US-012

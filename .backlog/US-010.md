# US-010 - Réception et consultation d'un exercice

**En tant que** joueur

**Je veux** recevoir un exercice correspondant aux filtres et voir son énoncé ainsi que le code buggé

**Afin de** comprendre le défi à résoudre.

## Critères d'acceptation

- Un exercice actif est sélectionné aléatoirement selon la difficulté, le langage et la catégorie choisis.
- L'écran de jeu affiche le titre, le contexte narratif, la difficulté, la catégorie et le code en lecture seule coloré.
- Les problèmes attendus et la solution restent cachés pendant toute la phase de jeu.

**Dépendances :** US-009
